# Project Randomizer — Proyectos Miguel

Aplicación web pequeña para elegir un proyecto al azar, filtrarlo por categoría y recibir una misión concreta para comenzar a trabajar.

## Funciones

- Crear categorías personalizadas.
- Seleccionar una categoría o usar **Todas**.
- Agregar y eliminar proyectos.
- Asignar cada proyecto a una categoría.
- Añadir misiones iniciales opcionales; si se omiten, la app crea tres misiones genéricas.
- Elegir un proyecto al azar.
- Elegir otra misión del proyecto seleccionado.
- Persistencia automática mediante `localStorage`.
- Diseño responsive inspirado en el mockup de referencia.

## Uso local

Abre `index.html` directamente en un navegador moderno o sirve la carpeta con cualquier servidor HTTP estático.

## GitHub Pages

El repositorio incluye un flujo de GitHub Actions para desplegar el contenido estático en GitHub Pages cuando Pages esté configurado para usar **GitHub Actions** como origen de publicación.
